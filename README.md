
# 🤖 Lumo AI

Lumo AI est un chatbot intelligent développé avec Django, utilisant LangChain côté backend et une interface web en HTML, CSS et JavaScript.

---

## 🚀 Aperçu

Lumo AI est une application web de chatbot qui permet aux utilisateurs d’interagir avec une IA via une interface simple et rapide.

Le backend est construit avec Django et LangChain pour gérer la logique du chatbot et les interactions avec le modèle IA.

---

## 🧠 Objectif du projet

* Créer un chatbot IA intégré dans une application web
* Apprendre à utiliser LangChain dans un backend Django
* Connecter frontend et backend pour une expérience fluide
* Comprendre l’architecture d’une application IA complète

## 📦 Installation

Clone le projet :

```bash
git clone https://github.com/ton-utilisateur/lumo-ai.git
cd lumo-ai
```

Créer un environnement virtuel :

```bash
python -m venv venv
source venv/bin/activate  # Mac/Linux
venv\Scripts\activate     # Windows
```

Installer les dépendances :

```bash
pip install -r requirements.txt
```

---

## ⚙️ Lancer le projet

Appliquer les migrations :

```bash
python manage.py migrate
```

Lancer le serveur :

```bash
python manage.py runserver
```

Puis ouvrir dans le navigateur :

```
http://127.0.0.1:8000/
```
